# 🌟 Hikari Desktop Environment

Hikari is a custom Wayland window manager that blends the visual elegance of Hyprland with the simplicity and performance of Sway.

## ✨ Features

- **Wayland-native**: Uses `wlroots` and `hikari` for full modern Wayland support.
- **Atomic Updates**: Based on VanillaOS atomic architecture.
- **Beautiful Defaults**: Arc theme, Papirus icons, Waybar, and tofi/wofi launchers.
- **Minimal Dependencies**: No bloat, only what you need.
- **User-Friendly**: Preconfigured and easy to extend.

## 🧰 Installed Software

- hikari, wlroots, waybar, foot, kitty, lxappearance
- tofi, wofi, rofi (launchers)
- arc-theme, papirus-icon-theme

## 🚀 Getting Started

Boot into the system and `hikari` will launch automatically.

> Customize the WM via `~/.config/hikari/config`.
